실제 앱과 영상의 차이

실제 차량 앱은 Grok에서 가져온 정적인 곡선과 코드로 움직이는 점 하나를 사용합니다. 점과 안내는 4초 들숨·4초 날숨의 세션 시간에 맞춰 진행하며, 일시정지하면 시간·안내·점이 함께 멈춥니다.

영상의 자동 네 장면 전환, 테마 페이드와 일시정지 화면의 후광 움직임은 쇼릴 참고 표현입니다. 실제 앱이 자동으로 테마를 바꾸거나 일시정지 중 계속 움직인다는 뜻은 아닙니다. Pearl·Umber 영상 역시 디자인 참고 자료입니다.

코드 모션과 10초 루프도 비교하기

루프용 소스 파일도 이 페이지에서는 자동 반복하지 않습니다. 브라우저의 재생 조작으로 각각 비교하세요.

02 / 직접 확인하기

처음부터 계속하기까지

아래 순서는 연결 화면과 차량 앱에서 직접 진행합니다.

  1. 폰에서 연결된 프리셋 선택

    연결을 완료한 폰의 프리셋 화면에서 사용할 선호를 고릅니다.

  2. 차량의 연결된 프리셋 확인

    차량 화면에 같은 이름과 선호가 도착했는지 확인합니다. 수신만으로 쉼은 시작되지 않습니다.

  3. 이 선호로 쉬기 준비

    차량 화면에서 준비를 누른 뒤 선택한 내용을 확인합니다. 설정의 “I choose this preset here.” 체크박스로 직접 확인하고, 합성 상태 Parked를 선택하세요.

  4. 3분 쉬기

    차량 화면에서 직접 누릅니다. 실행 중 남은 시간과 Graphite의 점이 같은 세션에 맞춰 진행되는지 확인합니다.

  5. 일시정지

    남은 시간과 점의 위치를 기억하고 잠시 기다립니다. 둘 다 같은 위치에 멈춰 있어야 합니다.

  6. 계속하기

    직접 누른 뒤 멈춘 지점에서 이어지는지 확인합니다. 일시정지 중 기다린 시간은 쉼 시간에 포함되지 않습니다.

중단과 회복도 확인해 보세요

차량의 연결·설정을 열고 합성 상태 Call 또는 Driving을 누르면 쉼이 멈춥니다. Parked를 눌러 허용 조건을 복구해도 자동으로 이어지지 않습니다. 쉬기 화면으로 돌아가기 → 계속하기를 직접 눌러 재개합니다.

이 조작은 테스트용 합성 상태입니다. 실제 통화·주차 상태 감지 또는 차량 기능 제어를 의미하지 않습니다.
